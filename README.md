Download the dataset and place it in the data folder. After modifying the file path, run main_Transformer_TimeCL.py to start training.  
You can also directly load weight files from the checkpoint folder for testing and classification prediction.  
Due to the large size of the dataset and some weight files (MUUFL), they cannot be uploaded directly. If needed, please contact us directly.
